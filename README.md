# Saved Draw

Local site for your Instagram saves: import an export or paste links, draw one at random, mark Completed or Won't do.

Data stays in this browser's IndexedDB — Instagram exports are never uploaded or committed.

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually http://localhost:5173).

## GitHub Pages

Pushes to `main` build with Vite and deploy via GitHub Actions. The site base path is `/saved-draw/`.
